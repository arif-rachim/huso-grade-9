## 📄 Page 1: Cells, molecules, energy, transport

### Biomolecules
| Class | Building block | Main job | Elements |
|---|---|---|---|
| Carbohydrates | monosaccharides (e.g. glucose) | quick energy, structure (cellulose) | C, H, O |
| Lipids (fats, oils) | fatty acids + glycerol | stored energy, membranes | C, H, O |
| Proteins | amino acids | enzymes, structure, transport, antibodies | C, H, O, N (+ S) |
| Nucleic acids (DNA, RNA) | nucleotides | store and pass on information | C, H, O, N, P |

### Central dogma
**DNA → (transcription) → mRNA → (translation) → protein**, and DNA → (replication) → DNA.
- Base pairs: **DNA** A–T and G–C · **RNA** A–**U** and G–C. **Codon** = 3 bases = 1 amino acid · AUG = start.
- **RNA processing:** add a 5′ cap and a poly-A tail, **cut out introns**, join exons.
- Replication is **semiconservative** (each new DNA = 1 old + 1 new strand).

### Cell organelles (13 + cytoplasm)
| Organelle | Job |
|---|---|
| Nucleus | holds DNA, controls the cell |
| Ribosome | makes proteins |
| Mitochondria | aerobic respiration, makes ATP |
| Chloroplast | photosynthesis (plants, algae) |
| Endoplasmic reticulum | rough: proteins · smooth: lipids |
| Golgi | modifies, sorts and packages |
| Lysosome | digests waste (enzymes) |
| Cell membrane | controls what goes in and out |
| Vacuole | storage; big central one in plants |
| Cell wall | support: plants (cellulose), fungi, bacteria |
| Peroxisome | breaks down fatty acids, detoxifies H₂O₂ |
| Centriole | spindle fibers in animal cell division |
| Cytoskeleton | shape, support, movement |
| Cytoplasm | jelly where reactions happen |

- **Prokaryote** (bacteria): no nucleus (DNA in the nucleoid), no membrane-bound organelles, small · **Eukaryote:** true nucleus + organelles.
- **Plant vs animal:** plant has **cell wall, chloroplasts, large vacuole**; animal has centrioles, small vacuoles.
- **Magnification = image size ÷ actual size** · 1 mm = 1000 µm.

### Cell division
| | Mitosis | Meiosis |
|---|---|---|
| Divisions | 1 | 2 |
| Cells made | 2, **identical** | 4, **different** |
| Chromosomes | stay diploid (2n) | halved: haploid (n) |
| Where / why | body cells: growth, repair | gonads: gametes (sperm, egg) |

**Mitosis phases:** **P**rophase → **M**etaphase → **A**naphase → **T**elophase (+ cytokinesis).

### Photosynthesis vs respiration
| | Photosynthesis | Aerobic respiration |
|---|---|---|
| Equation | 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ | C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + energy |
| Energy | stored (needs light) | released |
| Where | chloroplasts | mitochondria (all living cells) |
- **Anaerobic:** yeast and plants: glucose → **ethanol + CO₂** (+ a little energy) · muscles: glucose → **lactic acid** (+ a little energy).
- **Rate of photosynthesis** depends on light, CO₂, temperature, water, chlorophyll. The factor in **shortest supply** limits it (a flat part of a graph).

## 📄 Page 2: Body systems, ecology, classification

### Circulatory system
- **Heart path:** body → **vena cava** → right atrium → right ventricle → **pulmonary artery** → lungs → **pulmonary veins** → left atrium → left ventricle → **aorta** → body.
- **Double circulation:** pulmonary (heart ↔ lungs) + systemic (heart ↔ body). Left ventricle wall is the **thickest**.
- **Blood groups:** A (A antigen) · B · **AB** (both antigens, no antibodies = **universal acceptor**) · **O** (no antigens = **universal donor**).
- **Lymphatic system:** a one-way, parallel network that returns tissue fluid to the blood.

### Digestion and nutrition
- **Path:** mouth → esophagus → stomach → small intestine (absorption) → large intestine → rectum → anus.
| Gland | Makes |
|---|---|
| Salivary | amylase (starch → sugar) |
| Gastric | HCl + pepsin (protein) |
| Liver | **bile** (emulsifies fat; no enzyme) |
| Pancreas | enzymes for starch, protein, fat |
- **Deficiency diseases:** vitamin A → night blindness · C → scurvy · D → rickets · B₁ → beriberi · iron → anemia · iodine → goiter · protein → kwashiorkor.

### Breathing, excretion, nerves
- **Air path:** nose → pharynx → larynx → trachea → bronchi → bronchioles → **alveoli** (gas exchange by diffusion).
- **Inhale:** diaphragm contracts and flattens, ribs up and out, volume up, pressure down. **Exhale:** the reverse.
- **Excretion:** kidneys (urea, water, salts) · sweat glands (water, salts) · lungs (CO₂, water vapor). **Urine path:** kidney → ureter → bladder → urethra.
- **Brain:** cerebrum (thinking, voluntary) · cerebellum (balance, coordination) · medulla (heartbeat, breathing).
- **Reflex arc:** stimulus → receptor → **sensory neuron** → spinal cord → **motor neuron** → effector → response.

### Endocrine and immune
| Gland | Location | Hormone | Job |
|---|---|---|---|
| Thyroid | neck | thyroxine | controls metabolism |
| Adrenal | on top of the kidneys | adrenaline | fight or flight |
| Pancreas | behind the stomach | insulin, glucagon | blood sugar |
| Pituitary | base of the brain | growth hormone, others | "master gland" |
- **Innate** immunity: fast, general (skin, phagocytes) · **Adaptive:** slower first time, specific, **memory** (B cells make **antibodies**, T cells).
- **Allergy:** the body over-reacts to a harmless allergen (dust, pollen, mites, some foods).

### Ecology and classification
- **Producers** (plants) → **primary consumers** (herbivores) → **secondary consumers** → decomposers return nutrients. Arrows in a food chain point to **who eats**.
- **Symbiosis:** mutualism (+/+) · commensalism (+/0) · **parasitism** (+/−) · **predation** (+/−).
| Kingdom | Cells | Nutrition | Example |
|---|---|---|---|
| Monera | prokaryote | various | bacteria |
| Protista | eukaryote, mostly single | various | Amoeba |
| Fungi | eukaryote, cell wall | absorb food (saprophytes) | mould, yeast |
| Plantae | eukaryote, cell wall | make food | moss, tree |
| Animalia | eukaryote, no wall | eat food | fish to humans |
- **Vertebrates:** fish, amphibians, reptiles, birds, mammals. **Invertebrates:** no backbone.

### Tissues
- **Connective:** bone, cartilage, blood, **ligament** (bone ↔ bone), **tendon** (muscle ↔ bone).
- **Muscle:** striated (skeletal, voluntary) · smooth (organ walls, involuntary) · cardiac (heart, involuntary).
